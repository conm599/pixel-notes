# 🚀 Pixel Suite 傻瓜式部署教程（从零到上线）

> 适用：任何一台全新的 Ubuntu/Debian VPS。
> 全程大约 30 分钟。遇到问题先看最底下的「常见翻车点」。

---

## 第 0 步：你需要准备什么

| 东西 | 说明 |
|---|---|
| 一台 VPS | Ubuntu 20/22 或 Debian 11，最低 1 核 1G |
| 一个域名 | 例如 `example.com`，并能把子域名解析到 VPS |
| 本仓库代码 | `git clone -b pixel-suite https://github.com/conm599/taowa-projects.git` |

**域名解析**（去你的域名服务商后台添加两条 A 记录）：

```
notes.example.com  →  A  →  你的VPS的IP
img.example.com    →  A  →  你的VPS的IP
```

> 前缀随便起（`notes`/`img` 只是例子）。**两个子域名必须在同一个主域名下**，这样两站才能共享登录。

---

## 第 1 步：装环境（一条命令复制粘贴）

SSH 登录 VPS 后，整段执行：

```bash
apt update && apt install -y nginx mariadb-server php-fpm php-mysql php-gd php-mbstring php-curl php-cli certbot python3-certbot-nginx unzip
```

装完启动服务：

```bash
systemctl enable --now nginx mariadb php7.4-fpm   # Ubuntu 22 是 php8.1-fpm，按实际版本
```

建数据库（把 `你的密码` 换成一个强密码，**记下来**）：

```bash
mysql -e "CREATE DATABASE pixel_suite CHARACTER SET utf8mb4;"
mysql -e "CREATE USER 'pixel'@'localhost' IDENTIFIED BY '你的密码';"
mysql -e "GRANT ALL PRIVILEGES ON pixel_suite.* TO 'pixel'@'localhost'; FLUSH PRIVILEGES;"
```

> 便签和图床共用这个库（表前缀不同不会冲突）。

---

## 第 2 步：放代码

```bash
mkdir -p /var/www/hosting /var/www/tuchang
git clone -b pixel-suite https://github.com/conm599/taowa-projects.git /tmp/ps
cp -r /tmp/ps/bianqian/* /var/www/hosting/
cp -r /tmp/ps/tuchang/*   /var/www/tuchang/
chown -R www-data:www-data /var/www/hosting /var/www/tuchang
```

**建表**（两站首次访问会自动自愈建表，也可手动执行）：

```bash
mysql pixel_suite < /tmp/ps/docs/sql/init.sql   # 如仓库未带 init.sql 可跳过，走自愈
```

---

## 第 3 步：nginx 站点配置

创建 `/etc/nginx/sites-available/pixel`：

```nginx
server {
    listen 80;
    server_name notes.example.com img.example.com;
    root /var/www/hosting;          # 便签
    index index.php;

    location / {
        try_files $uri $uri/ /index.php?$query_string;
    }
    location ~ \.php$ {
        include snippets/fastcgi-php.conf;
        fastcgi_pass unix:/run/php/php7.4-fpm.sock;
    }
    # 图床走同一 PHP 进程池即可（tuchang 目录由代码内部跳转/入口区分）
    location /i.php { fastcgi_pass unix:/run/php/php7.4-fpm.sock; include snippets/fastcgi-php.conf; }
}
```

> 📌 实际生产配置在仓库 `tuchang/nginx/` 有归档样例，可整段参考。

启用并申请 HTTPS 证书：

```bash
ln -s /etc/nginx/sites-available/pixel /etc/nginx/sites-enabled/
nginx -t && systemctl reload nginx
certbot --nginx -d notes.example.com -d img.example.com
```

---

## 第 4 步：/admini/ 安装向导（核心步骤，全程点鼠标）

浏览器打开：**`https://notes.example.com/admini/`**

你会看到「① 首次安装向导」，按表格填：

| 分组 | 填什么 |
|---|---|
| 管理员账号 | 自己起用户名 + 密码（≥8 位，**这就是你的最高管理员密码**） |
| 便签数据库 | 主机 `localhost` / 端口 `3306` / 库名 `pixel_suite` / 用户 `pixel` / 密码=第 1 步记下的 |
| 图床数据库 | 同上（同一个库） |
| 图床常量 | 邀请码自己起（注册用）、管理密令（**默认=管理员密码**）、配额按需 |
| 站点域名 | 便签 `notes.example.com` / 图床 `img.example.com` |
| TTS | 没有语音服务就全部留空 |

点「**完成安装并锁定**」——配置写入 `/var/www/suite-config.php`（webroot 外，安全），安装入口永久关闭。

✅ **部署完成**。打开 `https://notes.example.com` 就是便签，`https://img.example.com` 就是图床，一次登录双站通用。

---

## 日常管理

- **改配置**：`https://notes.example.com/admini/` → 管理员密码登录 → 改完点「保存全部（立即生效）」
- **管理图床用户/配额**：图床顶栏「⚙ 管理」（或直接访问 `img.example.com/adminws.php`，输管理密令）
- **新增用户**：便签注册第一个账号自动是管理员；图床用邀请码注册

---

## 常见翻车点（血泪清单）

| 症状 | 原因 | 解法 |
|---|---|---|
| 两站全部 500 | `suite-config.php` 权限或内容坏 | `chown www-data:www-data /var/www/suite-config.php && chmod 600 它`；内容坏了进 /admini 重新保存 |
| /admini 保存报「写入失败」 | `/var/www` 目录不可写 | `chown root:www-data /var/www && chmod 775 /var/www` |
| 管理后台进不去 | 还没输过密令 | 先访问 `adminws.php` 输一次密令，顶栏就有入口了 |
| 改了 JS/CSS 不生效 | 浏览器/缓存 | 代码里 bump `?v=` 版本号（改前端必做） |
| 两站不共享登录 | 两个子域名不在同一主域名下 | 换成同一主域名的两个子域 |
