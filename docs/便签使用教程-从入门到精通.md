# 📝 便签使用教程（从入门到大师）

> 按难度分四级，跟着 level 走。每一级都不需要看代码。

---

## 🟢 低难度（会用浏览器就会用）

### 记你的第一条便签
1. 登录后点右上的 **＋ 新建便签**
2. 上面写标题，下面写内容，**自动保存**（右上角会闪「已保存」）
3. 左侧列表点哪条就打开哪条

### 整理：文件夹
- 点顶部 **📁 新建文件夹**（比如「工作」「生活」）
- 点文件夹进入；左上角**面包屑**（🏠 主页 / 📁 工作）随时跳回
- 便签想挪进文件夹：打开便签 → 移动到 → 选目标文件夹

### 找东西
- 顶部**搜索框**：输标题或内容的任意片段，即时出结果，点击直达

---

## 🟡 中难度（多选与批量，效率翻倍）

### 三种选中方式
| 方式 | 操作 |
|---|---|
| 长按 | 按住便签卡 0.5 秒 |
| 框选 | 在空白处按住鼠标拖一个框 |
| 勾选 | 点卡片左上角的勾选框 |

- 选中后**底部操作栏**出现：删除 / 移动到 / 复制等
- **Ctrl+拖** = 在已有选择上追加
- **Esc** = 取消选择

### Windows 式剪贴板
- **Ctrl+X** 剪切 → 进目标文件夹 → **Ctrl+V** 粘贴（= 移动）
- **Ctrl+C** 复制 → 任意文件夹反复 **Ctrl+V**（= 创建副本）
- 剪贴板独立存在：切文件夹、取消选择都不会丢

### 分享
- 打开便签 → 分享 → 选时长 → 得到链接
- 链接任何人可看（只读），到期自动失效，随时可撤销

---

## 🔴 高难度（体系化使用）

### 文件夹嵌套
- 文件夹里可以再建文件夹（最深 5 层）
- 删除文件夹时：里面的便签和子文件夹**自动上移一级**，永远不会丢内容

### AI 整理与 AI 编辑
- 顶部 **✨ AI 整理**：AI 自动把便签分类进文件夹（执行前给你预览，可撤销）
- 编辑便签时对话 **AI**：让它改写/总结/翻译，改动以**差异确认**方式呈现，逐块接受
- 自有 API Key：⚙ 设置里填自己的 Key（不存服务器，浏览器直连）

### 备份与安全
- ⚙ 设置 → 数据备份：一键导出全部便签为 JSON
- 分享链接带 token+有效期，撤销立即失效
- 忘记密码：登录页走邮箱找回（需在注册时绑定邮箱）

### 图床联动
- 顶栏 **🖼 图床** 一键跳转（登录互通）
- 截图上传图床 → 外链直接贴进便签的 Markdown

---

## ⚫ 大师难度（Markdown 全语法 + 隐藏能力）

便签内容是 **完整 Markdown** 渲染，掌握以下语法你就是排版大师：

### 基础排版
```markdown
# 一级标题        ## 二级标题        ### 三级标题
**加粗**  *斜体*  ~~删除线~~  ==高亮==  ^上标^  ~下标~
> 引用块（嵌套可多层）
- 无序列表        1. 有序列表（支持两级嵌套）
[链接文字](https://example.com)
| 表格 | 语法 | 也有 |
|---|---|---|
```

### 代码块
````markdown
```js
console.log('任意语言，带语法高亮主题');
```
````

### 内嵌媒体（白名单）
```markdown
![图片](https://example.com/a.webp)
![B站视频](bilibili://BV1xx411c7mD)
![音频](https://example.com/song.mp3)     ← 自绘播放器，可存进度
![视频](https://example.com/v.mp4)
```

### 任务列表与脚注
```markdown
- [x] 已完成的事
- [ ] 待办
这里有个脚注[^1]
[^1]: 脚注内容在文末
```

### 大师心法
1. **一条便签一个主题**，用标题+分割线组织长内容
2. 善用 `==高亮==` 和任务列表做每日清单
3. 图床外链 + MD 图片语法 = 免费的个人图文库
4. 分享链接发群里 = 零成本发布页（手机端自适应）
5. 内容用 AI 编辑改到满意再保存，差异确认保证不会改坏
